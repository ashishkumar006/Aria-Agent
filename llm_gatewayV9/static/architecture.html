Architecture

One process on :8109 owns every secret, model call, channel, and durable memory. Callers rent capabilities over HTTP. Manage it from the Overview, Connections and System pages; the endpoint reference lives in /help.

Diagrams need internet once. The renderer loads from a CDN — if you are offline you will see the raw diagram source below instead of pictures. Everything else on this page works offline.
