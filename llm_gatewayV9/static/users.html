Users & keys
—

New user

A user gets their own token and their own provider keys. The agent presents the token on every call; the gateway bills and rate-limits that call against this user's keys, never the operator's. The token is shown once.

Users

Provider keys are encrypted at rest and shown masked. A user with no keys cannot make model calls — it is an error, not a silent fallback to the operator pool.
