# Gateway Docs (`llm_gatewayV9/docs/`)

Design notes and plans for gateway subsystems. The top-level
[`../README.md`](../README.md) is the operator guide; this folder holds the
deeper design docs.

| File | Topic |
|---|---|
| `AGENT_UI_PROTOCOLS.md` | The protocol contract between the agent and the console UI. |
| `CHANNEL_TOOL_CATALOGUE.md` | The full channel → tool catalogue (what each channel exposes). |
| `CODE_EDITOR_PLAN.md` | Plan for the code-editor surface. |
| `DOCUMENTS_PLAN.md` | The document store / generation design. |
| `TOOL_SPEC_CORE7.md` | The core-7 tool specifications. |

See also the repo-level `../../docs/` for cross-cutting architecture, and
`../ADAPTOR_KEYS_GUIDE.md` / `../GATEWAY_KEYS.md` for key setup (names only, never
values).
